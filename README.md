# 🚗 Vortex

A modern, responsive, and visually appealing car showcase landing page built with **React** and **Vite**.

Designed with a clean UI, smooth animations, glassmorphism effects, and a mobile-first responsive experience, Vortex demonstrates modern front-end development practices and component-based architecture.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/sadeghdev1/vortex.git
```

Navigate to the project:

```bash
cd vortex
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```

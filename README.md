# Vortex - Sport Car Landing (React + SCSS Modules)

Demo landing built from provided PDF design.  
Tech: React (JSX), SCSS Modules, Vite.

## Run locally
1. `npm install`  
2. `npm run dev`  
Open http://localhost:5173

## Structure
- `src/components/*` : component-based organization
- `src/pages/*` : routes (Home, Gallery)
- `src/styles/*` : global variables and mixins

This is a starter, placeholder images used. Replace assets in `src/assets/images` and add your font in `src/assets/fonts`.
